# KICE 프로토 차시 시연

아스펜 원본에서 「로컬 내보내기」한 프로토 5차시(zip 을 그대로 풀어 둠)를 GitHub Pages 로 보여 주는 시연 페이지.

- `index.html` — 맨 위 바에서 차시를 고르면 아래 iframe 에 그 차시의 `index.html` 을 연다. `#E12-KO-001` 처럼 주소에 차시 ID 를 붙이면 바로 그 차시.
- `E12-KO-001/`, `E12-MA-009/`, `E34-SO-002/`, `E34-SC-001/`, `E34-EN-001/` — 내보낸 zip 내용 그대로(data.js·wgts·asset·js·css·corp·fonts).
